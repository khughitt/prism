Consider global or multi-parameter modes/subconfigurations informed by recorded parameter edits and interactions. If useful, expose only one or two important controls near the top of the UI. Preserve predictable behavior: adaptive UI can add complexity and become counterintuitive. Establish a concrete mode and explain which parameters it changes before implementing anything. Reuse prism-3e59b5 for edit data and learned ranges/defaults/scales, material-0c7eed for interaction structure, and prism-b315f9 for panel guidance. Existing context profiles are related, but do not by themselves decide this mode control.
