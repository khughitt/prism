Explore whether Noctalia's plugin surface (Lua widgets rendered by the shell) can host a rotary knob or LED-ring knob control. If it can: enlarge the dropdown panel, rotate it to landscape, show every knob at once with no collapsing groups, and color each knob by its group, like a VST rack. Prerequisite question: which controls Noctalia's plugin API exposes and whether a custom QML item can be shipped by a plugin.

## Notes

- 2026-09-05T08:13:14Z (main): Answered 2026-09-05: Noctalia plugin API 22 declarative UI offers slider, toggle, select, button, progress, graph, image, markdown only, and plugins cannot ship QML; a knob needs a contribution to Noctalia itself (checkouts under software/noctalia).
- 2026-09-06T09:26:22Z (main): Correction from prism-46ad16: the declarative vocabulary at v5.0.1 is column, row, box, label, glyph, image, separator, spacer, progress, button, graph, input, markdown, select, slider, toggle, scroll, dragSource, dropZone (src/scripting/ui_prelude.h). Still no custom control type from a plugin, so the knob conclusion stands.
