Explore whether Noctalia's plugin surface (Lua widgets rendered by the shell) can host a rotary knob or LED-ring knob control. If it can: enlarge the dropdown panel, rotate it to landscape, show every knob at once with no collapsing groups, and color each knob by its group, like a VST rack. Prerequisite question: which controls Noctalia's plugin API exposes and whether a custom QML item can be shipped by a plugin.
