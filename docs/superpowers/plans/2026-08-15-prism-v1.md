# prism v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A daemonless visual-parameter bus: canonical defs + sink manifests, a `prism` CLI whose `set` fans out to kitty (live socket), niri-glass (watched JSON), and niri (generated KDL include), plus a noctalia slider panel.

**Architecture:** Atomic files are the bus. `values.yaml` (user overrides) resolves against shipped defs into `resolved.json`; `prism set`/`apply` invoke idempotent per-sink `apply` executables. No daemon, no watchers — apply-on-write.

**Tech Stack:** Node 20+ ESM, sole runtime dep `yaml`, `node --test`. QML (Quickshell/noctalia) for the panel.

**Spec:** `docs/superpowers/specs/2026-08-15-prism-visual-bus-design.md` — read it before starting any task.

## Global Constraints

- Node `>=20`, `"type": "module"`, runtime deps: `yaml` only.
- Seam rule: files under `src/` and `bin/` MUST NOT contain the strings niri, kitty, ghostty, noctalia (case-insensitive). Enforced by `test/seam.test.js`.
- Fail early: invalid defs/manifests/values are loud errors; nothing clamps or falls back silently.
- All state writes are atomic (temp + rename) and go through the store lock.
- An explicit `set` fans out for its named key even when the stored value is unchanged.
- `prism apply` always re-resolves (`set` minus the value change).
- `resolved.json` carries **no** generation/sequence counter — staleness is per-sink, via each sink's own bound-param snapshot.
- There is **no `--liveness` flag**. Drag-rate protection lives only in the noctalia panel, which never samples a param that isn't fully `live`.
- **Bootstrap order for niri**: create the generated-file symlink, materialize its target, ensure the ignored Noctalia include exists (an empty KDL placeholder is valid), validate the tracked config by explicit path, and only then link that directory into `~/.config/niri`. With no running niri, setup may accept `prism apply niri`'s reload failure only after proving the target is nonempty and was atomically replaced by that invocation (different device+inode); the validated config loads on first start, after which the user runs `prism apply niri` to reload and clear the failed sink status. With a running niri, setup reloads again after exposing the new directory. A dangling `include` makes niri reject its entire config (verified), so this ordering is a correctness requirement, not tidiness.
- Sink `apply` programs run **outside** the store lock; one wedged sink must never block other writers. Sinks lagging `resolved.json` is a documented, `doctor`-detected, `apply`-repaired condition.
- Conventional commits; NO AI-attribution trailers.
- Tasks marked **[dotfiles]** run in `~/d/dotfiles` (a separate git repo); all others in `~/d/prism`.
- **NEVER `git add -A` (or `git add .`) in the dotfiles repo** — its tree carries unrelated modifications. Stage the exact paths each task names, then run `git diff --cached --name-only` and confirm the list contains only those paths before committing.
- Generated sink outputs are machine-local: written under `~/.local/state/prism/generated/`, reached from config paths via setup-created symlinks (spec: "Generated-file targets are machine-local").
- `withLock` is async (ported from familiar), so `fanOut`, the CLI verbs, and `run()` are async throughout.
- Tests must not touch the real HOME: every test sets `PRISM_CONFIG_DIR`/`PRISM_STATE_DIR` to a temp dir.
- **Tests must not depend on each other.** Node runs a file's top-level tests sequentially, so a test that quietly relies on its predecessor's writes passes in a full run and fails under `--test-name-pattern` — for a reason unrelated to the code. Any suite that mutates the store resets it in `beforeEach` and arranges its own preconditions. Fixture teardown registers with `t.after()` **before** the mutation it undoes, so a failing assertion cannot poison the rest of the file.

```js
// src/store.js
import fs from 'node:fs';
import path from 'node:path';

export function writeJsonAtomic(file, data) {
  fs.mkdirSync(path.dirname(file), { recursive: true });
  const tmp = path.join(path.dirname(file), `.${path.basename(file)}.${process.pid}.tmp`);
  fs.writeFileSync(tmp, JSON.stringify(data, null, 2) + '\n');
  fs.renameSync(tmp, file);
}

export function readJson(file, fallback) {
  try { return JSON.parse(fs.readFileSync(file, 'utf8')); }
  catch (err) {
    if (err.code === 'ENOENT') return fallback;
    throw err;
  }
}
```

```js
// src/defs.js
import fs from 'node:fs';
import path from 'node:path';
import { parse } from 'yaml';

export const TYPES = ['float', 'int', 'bool', 'color', 'enum', 'string', 'list'];
export const CONTROLS = ['slider', 'toggle', 'color', 'select', 'none'];

export function loadDefs(dir) {
  const defs = new Map();
  const files = fs.readdirSync(dir).filter((f) => f.endsWith('.yaml')).sort();
  if (files.length === 0) throw new Error(`no def files in ${dir}`);
  for (const f of files) {
    const list = parse(fs.readFileSync(path.join(dir, f), 'utf8'));
    if (!Array.isArray(list)) throw new Error(`${f}: expected a YAML list of defs`);
    for (const def of list) {
      validateDef(def, f);
      if (defs.has(def.key)) throw new Error(`duplicate def ${def.key} (${f})`);
      defs.set(def.key, def);
    }
  }
  return defs;
}

export function validateDef(def, src) {
  const fail = (msg) => { throw new Error(`invalid def ${def?.key ?? '?'} (${src}): ${msg}`); };
  if (typeof def?.key !== 'string' || !/^[a-z][a-zA-Z0-9]*(\.[a-z][a-zA-Z0-9]*)+$/.test(def.key)) fail('bad key');
  if (!TYPES.includes(def.type)) fail(`type must be one of ${TYPES.join('|')}`);
  if (!CONTROLS.includes(def.ui?.control)) fail(`ui.control must be one of ${CONTROLS.join('|')}`);
  if (typeof def.ui?.group !== 'string') fail('ui.group required');
  if (typeof def.description !== 'string') fail('description required');
  if (def.type === 'enum' && !Array.isArray(def.values)) fail('enum requires values');
  if (def.type === 'list' && def.items !== 'string') fail('list requires items: string');
  if ((def.type === 'list' || def.type === 'string') && def.ui.control !== 'none') fail(`${def.type} must declare control: none`);
  if ((def.type === 'float' || def.type === 'int')
      && !(Array.isArray(def.range) && def.range.length === 2)) fail('numeric def requires range');
  if (def.default === undefined) fail('default required');
}
```

```js
// src/values.js
import fs from 'node:fs';
import path from 'node:path';
import { parse, stringify } from 'yaml';
import { valuesPath } from './paths.js';

export function readValues() {
  try { return parse(fs.readFileSync(valuesPath(), 'utf8')) ?? {}; }
  catch (err) {
    if (err.code === 'ENOENT') return {};
    throw err;
  }
}

export function writeValues(values) {
  const file = valuesPath();
  fs.mkdirSync(path.dirname(file), { recursive: true });
  const tmp = `${file}.${process.pid}.tmp`;
  fs.writeFileSync(tmp, stringify(values));
  fs.renameSync(tmp, file);
}

export function parseCliValue(def, str) {
  const fail = () => { throw new Error(`${def.key}: cannot parse ${JSON.stringify(str)} as ${def.type}`); };
  switch (def.type) {
    case 'float': { const n = Number(str); if (!Number.isFinite(n) || str.trim() === '') fail(); return n; }
    case 'int': { const n = Number(str); if (!Number.isInteger(n) || str.trim() === '') fail(); return n; }
    case 'bool': if (str === 'true') return true; if (str === 'false') return false; fail(); break;
    case 'color': if (!/^#([0-9a-fA-F]{6}|[0-9a-fA-F]{8})$/.test(str)) fail(); return str;
    case 'enum': if (!def.values.includes(str)) fail(); return str;
    case 'list': {
      let v; try { v = JSON.parse(str); } catch { fail(); }
      if (!Array.isArray(v)) fail(); return v;
    }
    case 'string': return str;
    default: fail();
  }
}

export function validateValue(def, v) {
  const fail = (msg) => { throw new Error(`${def.key}: ${msg}`); };
  switch (def.type) {
    case 'float': if (typeof v !== 'number' || !Number.isFinite(v)) fail('not a number'); break;
    case 'int': if (!Number.isInteger(v)) fail('not an integer'); break;
    case 'bool': if (typeof v !== 'boolean') fail('not a boolean'); break;
    case 'color': if (typeof v !== 'string' || !/^#([0-9a-fA-F]{6}|[0-9a-fA-F]{8})$/.test(v)) fail('not a #rrggbb[aa] color'); break;
    case 'enum': if (!def.values.includes(v)) fail(`not one of ${def.values.join(', ')}`); break;
    case 'list':
      if (!Array.isArray(v)) fail('not a list');
      if (v.some((el) => typeof el !== 'string')) fail('list elements must be strings');
      break;
    case 'string': if (typeof v !== 'string') fail('not a string'); break;
  }
  if ((def.type === 'float' || def.type === 'int')
      && (v < def.range[0] || v > def.range[1])) {
    fail(`${v} outside range [${def.range[0]}, ${def.range[1]}]`);
  }
}
```

```js
// src/resolve.js
import { validateValue } from './values.js';
import { writeJsonAtomic } from './store.js';
import { resolvedPath } from './paths.js';

export function resolveParams(defs, values) {
  for (const key of Object.keys(values)) {
    if (!defs.has(key)) throw new Error(`unknown param ${key} in values`);
  }
  const params = {};
  for (const [key, def] of defs) {
    const v = key in values ? values[key] : def.default;
    validateValue(def, v);
    params[key] = v;
  }
  return params;
}

export function writeResolved(defs, values) {
  const resolved = { params: resolveParams(defs, values) };
  writeJsonAtomic(resolvedPath(), resolved);
  return resolved;
}
```

```js
// src/manifest.js
import fs from 'node:fs';
import path from 'node:path';
import { parse } from 'yaml';

export const LIVENESS = ['live', 'reload', 'restart'];

export function loadManifests(dir, defs) {
  if (!fs.existsSync(dir)) return [];
  const manifests = [];
  for (const entry of fs.readdirSync(dir, { withFileTypes: true })) {
    if (!entry.isDirectory()) continue;
    const file = path.join(dir, entry.name, 'manifest.yaml');
    if (!fs.existsSync(file)) continue;
    const m = parse(fs.readFileSync(file, 'utf8'));
    if (typeof m?.sink !== 'string' || !Array.isArray(m.binds)) {
      throw new Error(`${file}: manifest needs sink and binds`);
    }
    for (const b of m.binds) {
      if (!defs.has(b.param)) throw new Error(`${file}: binds undefined param ${b.param}`);
      if (!LIVENESS.includes(b.liveness)) throw new Error(`${file}: bad liveness ${JSON.stringify(b.liveness)}`);
    }
    const generates = m.generates ?? [];
    if (!Array.isArray(generates) || generates.some((g) => typeof g !== 'string')) {
      throw new Error(`${file}: generates must be a list of file names`);
    }
    manifests.push({ sink: m.sink, dir: path.join(dir, entry.name), binds: m.binds, generates });
  }
  return manifests;
}
```

```js
// src/fanout.js
import { execFileSync } from 'node:child_process';
import path from 'node:path';
import { readJson, writeJsonAtomic } from './store.js';
import { withLock } from './lock.js';
import { sinkStatusPath, statusLockPath, resolvedPath } from './paths.js';

export function selectSinks(manifests, changedKeys) {
  return manifests.filter((m) => m.binds.some((b) => changedKeys.includes(b.param)));
}

export function boundParams(manifest, resolved) {
  return Object.fromEntries(manifest.binds.map((b) => [b.param, resolved.params[b.param]]));
}

function runApply(manifest, resolvedFile, keys) {
  execFileSync(path.join(manifest.dir, 'apply'), [resolvedFile, ...keys], { stdio: 'pipe' });
}

async function record(sink, entry) {
  await withLock(statusLockPath(), async () => {
    const status = readJson(sinkStatusPath(), {});
    status[sink] = entry;
    writeJsonAtomic(sinkStatusPath(), status);
  });
}

export async function fanOut({ manifests, resolved, changedKeys, runner = runApply }) {
  const applied = [];
  const failed = [];
  // The store lock is deliberately NOT held here: `apply` programs are
  // external processes talking to sockets and compositors, and one wedged
  // sink must not block every other writer (spec: Transactionality).
  for (const m of selectSinks(manifests, changedKeys)) {
    const at = new Date().toISOString();
    try {
      runner(m, resolvedPath(), changedKeys);
      await record(m.sink, { ok: true, at, params: boundParams(m, resolved) });
      applied.push(m.sink);
    } catch (err) {
      await record(m.sink, { ok: false, at, params: boundParams(m, resolved), error: String(err) });
      failed.push({ sink: m.sink, error: String(err) });
    }
  }
  return { applied, failed };
}
```

```js
// src/cli.js
import fs from 'node:fs';
import { isDeepStrictEqual } from 'node:util';
import { loadDefs } from './defs.js';
import { loadManifests } from './manifest.js';
import { readValues, writeValues, parseCliValue, validateValue } from './values.js';
import { resolveParams, writeResolved } from './resolve.js';
import { fanOut, boundParams } from './fanout.js';
import { readJson } from './store.js';
import { withLock } from './lock.js';
import { defsDir, integrationsDir, lockPath, sinkStatusPath, generatedPath } from './paths.js';

const ORDER = { live: 0, reload: 1, restart: 2 };

function load() {
  const defs = loadDefs(defsDir());
  const manifests = loadManifests(integrationsDir(), defs);
  return { defs, manifests };
}

function report({ failed }, print, eprint) {
  for (const f of failed) eprint(`prism: ${f.sink}: ${f.error}\n`);
  return failed.length === 0 ? 0 : 1;
}

export async function run(argv, opts = {}) {
  const print = opts.print ?? ((s) => process.stdout.write(s));
  const eprint = opts.eprint ?? ((s) => process.stderr.write(s));
  const [verb, ...rest] = argv;
  try {
    switch (verb) {
      case 'set': {
        // No flags: a stray one (notably the removed --liveness) is a caller
        // running against an older contract and must fail, not be ignored.
        if (rest.length !== 2) throw new Error('usage: prism set <key> <value>');
        const [key, valueStr] = rest;
        const { defs, manifests } = load();
        const def = defs.get(key);
        if (!def) throw new Error(`unknown param ${key}`);
        const value = parseCliValue(def, valueStr);
        validateValue(def, value);
        let resolved;
        await withLock(lockPath(), async () => {
          const values = readValues();
          // sparse rule: storing the default IS unsetting it
          if (isDeepStrictEqual(value, def.default)) delete values[key];
          else values[key] = value;
          writeValues(values);
          resolved = writeResolved(defs, values);
        });
        return report(await fanOut({ manifests, resolved, changedKeys: [key], runner: opts.runner }), print, eprint);
      }
      case 'unset': {
        const [key] = rest;
        const { defs, manifests } = load();
        // Orphan escape hatch: unset is the ONE verb that works on an undefined
        // key, provided values.yaml actually holds it. A pulled values.yaml can
        // name a param this host's defs don't define; without this the CLI would
        // be wedged until someone hand-edited YAML.
        if (!defs.has(key) && !(key in readValues())) throw new Error(`unknown param ${key}`);
        let resolved;
        await withLock(lockPath(), async () => {
          const values = readValues();
          delete values[key];
          writeValues(values);
          resolved = writeResolved(defs, values);   // throws if OTHER orphans remain
        });
        return report(await fanOut({ manifests, resolved, changedKeys: [key], runner: opts.runner }), print, eprint);
      }
      case 'get': {
        const { defs } = load();
        if (!defs.has(rest[0])) throw new Error(`unknown param ${rest[0]}`);
        print(JSON.stringify(resolveParams(defs, readValues())[rest[0]]) + '\n');
        return 0;
      }
      case 'list': {
        const { defs } = load();
        const params = resolveParams(defs, readValues());
        for (const key of Object.keys(params)) print(`${key} = ${JSON.stringify(params[key])}\n`);
        return 0;
      }
      case 'describe': {
        const { defs, manifests } = load();
        const values = readValues();
        const params = resolveParams(defs, values);
        const out = { params: [] };
        for (const [key, def] of defs) {
          const bindings = manifests.flatMap((m) =>
            m.binds.filter((b) => b.param === key).map((b) => ({ sink: m.sink, liveness: b.liveness })));
          const effectiveLiveness = bindings.length
            ? bindings.map((b) => b.liveness).sort((a, b) => ORDER[b] - ORDER[a])[0]
            : null;
          out.params.push({ key, type: def.type, range: def.range, values: def.values,
            default: def.default, value: params[key], modified: key in values,
            ui: def.ui, description: def.description, bindings, effectiveLiveness });
        }
        print(JSON.stringify(out, null, 2) + '\n');
        return 0;
      }
      case 'apply': {
        const { defs, manifests } = load();
        let resolved;
        await withLock(lockPath(), async () => { resolved = writeResolved(defs, readValues()); });
        const targets = rest.length ? manifests.filter((m) => rest.includes(m.sink)) : manifests;
        if (rest.length && targets.length !== rest.length) throw new Error(`unknown sink among: ${rest.join(', ')}`);
        const allKeys = [...new Set(targets.flatMap((m) => m.binds.map((b) => b.param)))];
        return report(await fanOut({ manifests: targets, resolved, changedKeys: allKeys, runner: opts.runner }), print, eprint);
      }
      case 'doctor': {
        const { defs, manifests } = load();       // throws on any invalid def/manifest
        const values = readValues();
        let problems = 0;

        // 1. Bootstrap: a missing generated target can stop niri from starting,
        //    so it outranks every other condition and reads differently.
        for (const m of manifests) {
          for (const name of m.generates) {
            if (!fs.existsSync(generatedPath(name))) {
              print(`doctor: ${m.sink}: generated file missing: ${name} — run 'prism apply ${m.sink}'\n`);
              problems++;
            }
          }
        }

        // 2. Orphans, BEFORE resolving — resolution throws on them, and a bare
        //    stack trace would not tell the user that `unset` is the way out.
        const orphans = Object.keys(values).filter((k) => !defs.has(k));
        for (const key of orphans) {
          print(`doctor: orphan value ${key}: no definition — run 'prism unset ${key}'\n`);
          problems++;
        }
        if (orphans.length) return 1;             // nothing below can run

        // 3. Per-sink staleness against each sink's own bound-param snapshot.
        const params = resolveParams(defs, values);
        const status = readJson(sinkStatusPath(), {});
        for (const m of manifests) {
          const s = status[m.sink];
          const expected = boundParams(m, { params });
          if (!s) { print(`doctor: ${m.sink}: never applied\n`); problems++; }
          else if (!s.ok) { print(`doctor: ${m.sink}: failed: ${s.error}\n`); problems++; }
          else if (!isDeepStrictEqual(s.params, expected)) { print(`doctor: ${m.sink}: stale (applied values differ from current)\n`); problems++; }
        }
        if (problems === 0) print('doctor: ok\n');
        return problems === 0 ? 0 : 1;
      }
      default:
        eprint(`usage: prism set|unset|get|list|describe|apply|doctor\n`);
        return 2;
    }
  } catch (err) {
    eprint(`prism: ${err.message}\n`);
    return 1;
  }
}
```

```js
// integrations/kitty/live.js
export function liveCommands(resolved, osWindows) {
  const active = resolved.params['terminal.background.opacity.active'];
  const inactive = resolved.params['terminal.background.opacity.inactive'];
  const commands = [['set-background-opacity', '--all', String(inactive)]];
  const focused = osWindows.find((window) => window.is_focused);
  const windowId = focused?.tabs?.flatMap((tab) => tab.windows ?? [])[0]?.id;
  if (windowId !== undefined) {
    commands.push(['set-background-opacity', '--match', `id:${windowId}`, String(active)]);
  }
  return commands;
}

export function applyLiveOpacity(resolved, kitten) {
  kitten(liveCommands(resolved, [])[0]);
  const osWindows = JSON.parse(kitten(['ls']).toString());
  const activeCommand = liveCommands(resolved, osWindows)[1];
  if (activeCommand) kitten(activeCommand);
}

export function kittySockets(procNetUnix) {
  const sockets = new Set();
  for (const line of procNetUnix.split('\n')) {
    const address = line.trim().split(/\s+/).at(-1);
    if (/^@dotfiles-kitty-\d+$/.test(address)) sockets.add(`unix:${address}`);
  }
  return [...sockets];
}

export function applyToKittySockets(resolved, procNetUnix, kitten) {
  const sockets = kittySockets(procNetUnix);
  if (sockets.length === 0) {
    throw new Error('no kitty remote-control sockets found matching unix:@dotfiles-kitty-<pid>');
  }
  for (const socket of sockets) {
    applyLiveOpacity(resolved, (args) => kitten(socket, args));
  }
}
```

### Task 18: noctalia plugin — serialized write queue

**Files:**
- Create: `integrations/noctalia-plugin/queue.mjs`, `test/plugin-queue.test.js`
- Modify: `integrations/noctalia-plugin/PrismClient.qml`, slider delegate

**Interfaces:**
- Consumes: `prism set <key> <value>` / `prism unset <key>` (Task 9).
- Produces: the spec's write contract — one in-flight subprocess, FIFO pending queue, release waits for drain — as a **pure, node-tested state machine** (`queue.mjs`, the niri-glass shared-module pattern: import-free, usable from both QML and node). The ordering logic is too important for manual verification alone.
  - `queue.mjs`: `newQueue() -> state`; `enqueue(state, item) -> {state, launch}`; `finish(state) -> {state, launch, drained}` where `item = {verb: 'set'|'unset', key, value?, sample}` and `launch` is the item to start now or `null`.
  - `sample: true` marks a mid-drag write. It is **only** a coalescing marker — it does not change the command line. (The earlier design had it select `--liveness live`; that flag is gone, since the panel already refuses to sample anything but a fully-live param, so the CLI filter could never filter anything.)
  - **Coalescing rule**: only a drag sample (`verb: 'set'`, `sample: true`) whose key matches the LAST pending item's sample coalesces (replaces it). Everything else — toggles, selects, unsets, group resets, cross-key writes — appends FIFO and is NEVER dropped: three rapid unsets must all execute, in order.
  - `argvFor(item) -> string[]` — `['prism','set',key,String(value)]` or `['prism','unset',key]`. Identical for samples and releases.
  - **QV4 constraint** (established in niri-glass): QML's JS engine cannot parse object spread — `queue.mjs` must use explicit object literals and `.slice()`/`.concat()`, or node tests pass while the plugin fails to load.

```js
// integrations/noctalia-plugin/queue.mjs — import-free, shared QML/node.
// QV4 (QML's JS engine) cannot parse object spread: explicit literals only.
export function newQueue() {
  return { inFlight: null, pending: [] };
}

function isSample(item) {
  return item !== null && item !== undefined
    && item.verb === 'set' && item.sample === true;
}

export function enqueue(state, item) {
  if (state.inFlight === null) {
    return { state: { inFlight: item, pending: state.pending }, launch: item };
  }
  const pending = state.pending.slice();
  const last = pending.length > 0 ? pending[pending.length - 1] : null;
  if (isSample(item) && isSample(last) && last.key === item.key) {
    pending[pending.length - 1] = item;   // coalesce this slider's stale sample only
  } else {
    pending.push(item);                   // discrete or cross-key: FIFO, never dropped
  }
  return { state: { inFlight: state.inFlight, pending: pending }, launch: null };
}

export function finish(state) {
  if (state.pending.length > 0) {
    const next = state.pending[0];
    return { state: { inFlight: next, pending: state.pending.slice(1) }, launch: next, drained: false };
  }
  return { state: { inFlight: null, pending: [] }, launch: null, drained: true };
}

export function argvFor(item) {
  if (item.verb === 'unset') return ['prism', 'unset', item.key];
  // `sample` affects coalescing only — never the command line.
  return ['prism', 'set', item.key, String(item.value)];
}
```

Run `npm test` → queue suite green.

```qml
// inside PrismClient.qml
import "./queue.mjs" as Q
property var q: Q.newQueue()

function set(key, value, isSample) { _push({ verb: "set", key: key, value: value, sample: isSample }); }
function unset(key) { _push({ verb: "unset", key: key }); }
function _push(item) {
    var r = Q.enqueue(q, item); q = r.state;
    if (r.launch) _launch(r.launch);
}
function _launch(item) {
    setProc.command = Q.argvFor(item);   // a Process; onExited calls _done(exitCode, stderrText)
    setProc.running = true;
}
function _done(code, err) {
    if (code !== 0) failed(err || "prism exited " + code);  // banner + refresh, never swallowed
    var r = Q.finish(q); q = r.state;
    if (r.launch) _launch(r.launch);
    else if (r.drained) drained();
}
```
